Lesson 1 · HTML

What is HTML?

~15 min · No setup

1. HTML is structure, not code

HTML (HyperText Markup Language) describes what things are — heading, paragraph, image, link. The browser decides how to show them. Think: HTML = skeleton, CSS = skin, JavaScript = brain.

House analogy

  • HTML — walls, doors, rooms (structure)
  • CSS — paint, furniture (style)
  • JavaScript — lights & plumbing (behavior)

2. Your first page in 30 seconds

Create index.html on your desktop, paste this, double-click to open:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, Infotris!</h1>
  <p>This is my first HTML page.</p>
</body>
</html>

You just shipped a website. No server needed.

3. Tags & attributes

Tags like <h1>...</h1> wrap content. Attributes add info: <html lang="en"> tells browser the language is English.

Try it now

Change the <h1> text to your name, save, and refresh. See it update instantly.
