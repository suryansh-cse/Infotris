Lesson 5 · HTML

Tables & Lists

~20 min

1. Tables — for tabular data only

Use tables when data belongs in rows/columns (like a spreadsheet). Never for page layout — use CSS instead.

<table>
  <caption>Skills Progress</caption>
  <thead>
    <tr><th scope="col">Skill</th><th scope="col">Level</th></tr>
  </thead>
  <tbody>
    <tr><td>HTML</td><td>Beginner</td></tr>
    <tr><td>CSS</td><td>Learning</td></tr>
  </tbody>
</table>

<th> = header, scope="col" helps screen readers, caption = table title.

2. Lists deep-dive

<ol>
  <li>Learn HTML</li>
  <li>Practice</li>
  <li>Build project</li>
</ol>
<dl>
  <dt>HTML</dt><dd>Structure</dd>
  <dt>CSS</dt><dd>Style</dd>
</dl>
